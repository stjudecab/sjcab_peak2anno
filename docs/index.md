# sjcab_peak2anno

`sjcab_peak2anno` annotates genomic peak BED files to nearby genes, genomic
features, and chromatin states.

![peak2anno subcommand overview](peak2anno-subcommands.svg)

Use the [installation](install.md), [configuration](configuration.md),
[commands](commands.md), [input/output](input-output.md), and [Python API](api.md)
pages for setup, formats, configuration, and usage examples.

Source repository: [stjudecab/sjcab_peak2anno](https://github.com/stjudecab/sjcab_peak2anno).
